### 1. Review Website
Open `index.html` in your browser to see the complete design.

### 2. Update Business Info (Optional)
Edit these in `index.html`:
- Phone: `07 88 33 02 10` → your number
- Hours: Update `<div class="hour-row">` entries
- Service descriptions: Edit service cards

### 3. Choose Colors (Optional)

```css

--color-accent: #d4af37;         /* Gold */
```

## 10-Minute Deployment

### Option A: Netlify (Recommended - Easiest)
1. Go to https://app.netlify.com
2. Click "Add New Site" → "Deploy manually"
3. Drag & drop the `ljt-paysage` folder
4. ✅ Site is LIVE in 10 seconds!
5. Add custom domain: Dashboard → Domain Management

### Option B: Vercel (Fast Alternative)
1. Go to https://vercel.com
2. Connect your GitHub repo
3. Click "Deploy"
4. ✅ Automatic deployment from Git

### Option C: Free GitHub Pages
1. Create GitHub repository
2. Push files to main branch
3. Enable Pages in Settings
4. ✅ Live at: `username.github.io/ljt-paysage`

See `DEPLOYMENT.md` for detailed instructions.

Locations: HTML (multiple), CSS logo section, meta tags

### Change Phone Number
Find: `07 88 33 02 10`

Locations: Header, footer, contact section, schema

## Emergency Help

**Site won't load?**
- Check DNS propagation (24-48 hours)
- Verify files uploaded correctly
- Check hosting provider dashboard

**Form not working?**
- Test locally first (open index.html)
- Check browser console for errors
- Verify form endpoint configured

**Slow site?**
- Compress images (TinyPNG.com)
- Enable gzip on server
- Use CDN (Cloudflare, etc.)

**Mobile looks wrong?**
- Clear browser cache (Ctrl+Shift+R)
- Test in Chrome DevTools mobile view
- Verify viewport meta tag in HTML
